PROYECTO COLABORATIVO octubre / 2026

Agenda Telefónica (Hackathon)

Propósito: Desarrollar una aplicación backend para gestionar una agenda telefónica, permitiendo registrar, consultar, modificar y eliminar contactos mediante una estructura organizada y persistencia de datos.

Contexto

Proyecto desarrollado durante un hackatón con tiempo limitado, aplicando Java 17, Spring Boot y SQL para construír una solución backend funcional y organizada.

Desafío

Diseñar e implementar rápidamente las funcionalidades principales de la agenda, manteniendo una estructura de código clara y facilitando la integración del trabajo realizado por los diferentes integrantes del equipo.

Solución

Dividimos el proyecto por funcionalidades, organizamos el desarrollo mediante una arquitectura por capas y utilizamos Git y GitHub para trabajar de forma colaborativa, integrar cambios y mantener el código organizado.

Mi contribución

  • Desarrollador Backend / Implementé la lógica de gestión de contactos utilizando Java 17 y Spring Boot, aplicando principios de programación orientada a objetos.
  • Desarrollador Backend / Desarrollé operaciones CRUD para registrar, consultar, modificar y eliminar contactos, integrando la aplicación con la base de datos mediante SQL.
  • Desarrollador Backend / Organicé la lógica del sistema mediante una estructura por capas, separando responsabilidades para facilitar el mantenimiento y la integración de nuevas funcionalidades.

PROYECTO INDIVIDUAL octubre / 2026

AD-20-1 – Evaluación Final de Desarrollo de Aplicaciones

Propósito: Desarrollar una aplicación en JavaScript que integre funciones matemáticas y administración de usuarios, aplicando programación modular y pruebas unitarias para comprobar su correcto funcionamiento.

Contexto

Proyecto individual desarrollado como parte de la evaluación del módulo de Desarrollo de Aplicaciones de Generation, utilizando JavaScript, Node.js y Jest.

Desafío

Implementar operaciones matemáticas y funcionalidades de gestión de usuarios, contemplando validaciones, manejo de errores y diferentes escenarios de prueba para garantizar resultados correctos.

Solución

Desarrollé funciones independientes y clases para organizar la lógica de la aplicación. Implementé pruebas unitarias con Jest y utilicé el enfoque TDD para identificar y corregir errores, incluyendo la validación de división entre cero.

Mi contribución

  • Desarrollador JavaScript Junior / Implementé funciones matemáticas para operaciones básicas, promedios, factoriales, sucesiones y resolución de ecuaciones cuadráticas.
  • Desarrollador JavaScript Junior / Desarrollé las clases User y UserController para registrar, eliminar, consultar y buscar usuarios mediante ID y correo electrónico.
  • Desarrollador JavaScript Junior / Implementé pruebas unitarias con Jest para validar funcionalidades, controlar errores y comprobar distintos escenarios mediante TDD.

PROYECTO COLABORATIVO noviembre / 2024

Enigma de Aragón

Propósito: Concientizar a los alumnos de la FES Aragón sobre los problemas que puede ocasionar el consumo de bebidas y sustancias alucinógenas, así como su impacto en el desempeño profesional, con el fin de prevenir la deserción asociada al abuso de estas sustancias.

Contexto

Juego ambientado en 2D de aventura, plataforma y rompecabezas.

Desafío

Los principales retos fueron la integración de los recursos gráficos, la correcta detección de colisiones y el uso de partículas.

Solución

Se utilizaron recursos gráficos gratuitos, se reforzó el conocimiento sobre el uso adecuado de mallas en Unity y se limitó el uso de partículas para optimizar los recursos del hardware.

Mi contribución

  • Desarrollador Unity / Desarrollé y modifiqué scripts en C# con Unity para controlar personajes, colisiones, eventos e interfaces.
  • Desarrollador Unity / Implementé mecánicas de mecánicas de juego para movimiento, interacción con objetos y comportamiento de enemigos.
  • Desarrollador Unity / Integré y configuré escenas en Unity con modelos 3D, materiales y recursos visuales, realizando pruebas y ajustes.
